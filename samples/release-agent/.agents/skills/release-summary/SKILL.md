# Release Summary

## 입력

- 요약할 원문
- 원하는 길이와 대상 독자

## 수행 절차

1. 원문의 목적과 대상 독자를 확인합니다.
2. 핵심 사실, 결정 사항과 후속 행동을 구분합니다.
3. 원문에 없는 해석은 추가하지 않습니다.
4. 사용자가 지정한 길이에 맞춰 요약합니다.

## 출력 형식

- 핵심 요약
- 결정 사항
- 후속 행동
- 확인 필요 항목
