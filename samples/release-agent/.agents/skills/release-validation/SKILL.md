# Release Validation

## 입력

- 원문
- 검증할 요약문

## 수행 절차

1. 요약문의 각 핵심 주장을 원문과 대조합니다.
2. 근거가 없거나 과장된 주장을 표시합니다.
3. 원문의 결정 사항과 후속 행동이 누락되었는지 확인합니다.
4. 수정이 필요하면 원문 근거와 함께 수정 방향을 제시합니다.

## 출력 형식

- 확인된 주장
- 근거 부족 주장
- 누락 항목
- 최종 판정: `통과` 또는 `수정 필요`
